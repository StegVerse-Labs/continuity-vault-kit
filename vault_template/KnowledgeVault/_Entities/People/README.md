# People Index

This folder contains one file per important person in your life.

Purpose:
- Track relationships over time
- Link memories, events, and tags to individuals
- Preserve personal history in a structured, AI-readable way

Do not add every contact here — only people who appear in meaningful memories.

Files in this folder may be marked with a privacy level to control AI access.
