# Vault Health Check

Use this checklist when moving the vault to a new device or platform.

## Structure
- All top-level folders present
- _Index contains 3 index files
- _Meta contains vault.manifest.json

## Navigation
- Master Index opens
- Links to Notes, Research, Records folders work
- Genesis Entry opens

## File Integrity
- Markdown files open as readable text
- No files rely on proprietary formats

If these pass, the vault is structurally sound.
