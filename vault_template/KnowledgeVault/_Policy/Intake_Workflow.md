# Intake Workflow (iPhone-first)

## Daily capture
- Put everything into `00_Inbox/`

## Weekly processing (5–15 min)
1. Rename with the naming standard
2. Move into the correct folder
3. Add links into `_Index/` when important

## Monthly maintenance (10 min)
- Export any app-locked notes into Markdown/PDF and store in `01_Notes/`
- Mirror vault to secondary cloud (optional)
