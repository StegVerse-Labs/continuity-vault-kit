# KnowledgeVault (Template)

This template produces a portable personal vault.

- `canon/` is synced from StegDB (the authoritative doctrine + contract templates).
- Everything else in this folder is the kit’s user-facing structure and may evolve for usability.

If you want to propose changes to doctrine, edit StegDB:
`StegDB/canonical/overlays/KnowledgeVaultOverlay/canon/`
