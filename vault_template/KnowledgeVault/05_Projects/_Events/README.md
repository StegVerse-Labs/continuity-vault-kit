# Shared Memory Events

This folder contains **event containers** designed for multi-perspective memories:
birthdays, weddings, trips, reunions, etc.

Each event is a self-contained “memory space” with:
- a manifest (what this event is)
- participants + permissions
- media index (what’s been contributed)
- capture playbook (how to gather better footage)
- optional outputs (assembled films, 3D recon, exports)

## Naming
Use:
`YYYY-MM-DD — Event Name`

Example:
`2026-02-04 — Lily Birthday Party`
