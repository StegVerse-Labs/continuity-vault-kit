# Capture Playbook (Simple)

If you want a great highlight film (and possibly 3D later), ask 2–5 people to do this:

## 1) Establishing shots (10–20 seconds)
- Record the room/venue slowly.
- One clip from each corner if possible.

## 2) Key moments (10–30 seconds each)
- Cake / vows / gifts / speeches / first dance / etc.
- Capture reactions too (turn camera briefly to faces).

## 3) “Same moment, multiple angles” (optional)
- Two people record the same moment from different sides.

## Don’ts
- Don’t use heavy zoom.
- Avoid extremely dark clips if possible.
- Keep clips steady and short.

## Notes for privacy
Only capture what you’re comfortable sharing for this event.
