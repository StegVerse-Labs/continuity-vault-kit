# KnowledgeVault Backup & Export Guide
**How to create safe snapshots of your vault**

Your KnowledgeVault should exist in more than one place.  
Backups protect against device loss, account problems, or accidental deletion.

This guide explains simple, reliable backup methods.

---

## 🧠 Backup Principle

Use the **3‑2‑1 Rule**:

• **3 copies** of your vault  
• **2 different storage types**  
• **1 copy offline**

---

## 📦 Method 1 — Manual ZIP Snapshot (Recommended)

Best for iPhone-only users.

### Steps

1. Open **Files app**
2. Go to **iCloud Drive → KnowledgeVault**
3. Tap **Select** (top right)
4. Tap the **KnowledgeVault folder**
5. Tap the **… menu**
6. Choose **Compress**

This creates:

`KnowledgeVault.zip`

### Store this ZIP in:

• External drive  
• USB storage  
• Another cloud provider (optional)  

Do this once a month or after major updates.

---

## 💻 Method 2 — Computer Backup

If you use a Mac or PC:

### Mac (Finder)

1. Open iCloud Drive folder
2. Right‑click **KnowledgeVault**
3. Choose **Compress**
4. Copy ZIP to external drive

### Time Machine (Mac)

If your iCloud folder is synced locally, Time Machine will automatically include it.

---

## ☁️ Method 3 — Secondary Cloud Backup

Optional extra redundancy:

• Copy ZIP snapshot to:
  - Google Drive
  - Dropbox
  - Proton Drive
  - Encrypted cloud storage

Do **not** sync the live vault folder to multiple clouds simultaneously — only upload ZIP backups.

---

## 🔐 Encrypting Backups (Optional but Recommended)

If storing off iCloud:

### Mac
Right‑click ZIP → Encrypt

### Windows
Use 7‑Zip → Add to archive → Set password

### iPhone
Store ZIP inside an encrypted drive app if desired

Never lose the password — encrypted backups cannot be recovered.

---

## 🗓 Suggested Backup Schedule

| Frequency | Action |
|----------|-------|
Weekly | If vault changes often |
Monthly | Normal use |
After big projects | Immediate snapshot |

---

## 🔄 Restoring from a Backup

1. Locate your backup ZIP
2. Unzip into **Files → iCloud Drive**
3. Rename folder if needed
4. Replace missing files only

If structure is outdated, reinstall framework folders afterward (see Recovery Guide).

---

## 🧭 Final Rule

Backups protect your **life data**.  
GitHub protects the **framework**.

You can rebuild structure.  
You cannot recreate lost memories.
