# Format Preservation Policy

This vault prioritizes open, widely supported formats to ensure long-term readability.

Preferred formats:

| Content | Preferred | Acceptable | Avoid |
|--------|-----------|------------|-------|
| Notes | .md, .txt | .pdf | proprietary note formats |
| Docs | PDF/A | .docx | app-locked formats |
| Data | .csv, .json | .xlsx | binary databases |
| Images | .jpg, .png | .tiff | raw proprietary |
| Audio | .wav, .mp3 | .flac | app-only formats |

If a format becomes obsolete, convert to the preferred format and record the change in `Migration_Log.md`.
