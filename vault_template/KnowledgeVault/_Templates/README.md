# Templates

Use this folder for reusable note shapes.

Templates are optional. They exist to reduce friction when a recurring kind of note needs the same structure each time.

Recommended uses:

- first notes
- project notes
- decision logs
- conversation continuity summaries
- entity files
- review notes

Rules:

1. Templates are starting points, not requirements.
2. Remove sections you do not need.
3. Keep templates readable without special software.
4. Do not store sensitive data inside template files.
5. Human-authored notes remain authoritative.

For conversation continuity, see:

- `docs/CONVERSATION_CONTINUITY.md`
- `docs/examples/Reload_Packet_Example.md`
