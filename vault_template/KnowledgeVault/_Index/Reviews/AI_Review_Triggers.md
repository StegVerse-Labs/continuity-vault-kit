# AI Review Triggers

AI may suggest a review when:

- A project has had no updates for 3+ months
- A person marked as "seen often" has no recent linked memories
- A year in the Timeline has many memories but no summary
- A project marked "active" shows no new events
- A major event occurred (wedding, move, job change)

AI should:
- Suggest gently
- Never auto-edit
- Accept “not now” without repeated prompting
