# Quick Capture

When something happens and you just want to save it fast, start here.

You don’t need to organize it yet.

---

## ✍️ Write a Quick Note

Open:
`../00_Inbox/Quick_Notes.md`

Add:
- What happened
- Who was there (if known)
- Where you were (if known)
- Anything you don’t want to forget

Done. You can organize it later.

---

## 📸 Photo or Video

Save the media file into:
`../04_Media/`

Then add a quick note in:
`../00_Inbox/Quick_Notes.md`

---

## 🎙 Voice Note

Record a voice memo using your phone, save it in:
`../04_Media/`

Then add a short note in:
`../00_Inbox/Quick_Notes.md`
