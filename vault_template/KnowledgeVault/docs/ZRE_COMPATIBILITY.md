# ZRE Compatibility (StegVerse Style)

ZRE compatibility is **reflection-based**, not predictive.

## Lite Compatibility
Uses only zodiac sign emojis shared by both users (e.g., ♎️ + ♈️).
Output is a set of prompts designed to improve communication and understanding.

## Enhanced Compatibility
Uses `ZRE_ShareCard.json` files (translated symbolic profile only).
No raw birth data is exchanged.

## Prohibited
Compatibility must NOT:
- produce deterministic “scores” as truth
- claim outcomes (e.g., “this will fail/succeed”)
- be presented as advice or fate
