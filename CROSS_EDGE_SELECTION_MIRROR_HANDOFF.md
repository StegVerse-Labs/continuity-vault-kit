`CommunicationRuntimeJournal` now moves the production-facing persistence glue out of the SDK harness. It is transport-neutral and does not import StegTalk. It accepts already-produced selection, lease, edge-execution and recovery evidence and persists them through `KnowledgeVaultExecutionStore`.

It enforces:

```text
selection hash integrity
selection attempt/edge/bearer binding
lease attempt/edge/epoch binding
edge execution selection hash/attempt/edge/bearer/lease binding
edge execution receipt hash integrity
same execution receipt is durably idempotent
same idempotency key cannot bind a different execution receipt
ambiguous dispatch cannot claim side-effect absence
recovery cannot grant new authority
restart reconstruction of selection + lease + execution receipt + recovery state
```

KnowledgeVault still does not select a bearer and does not execute a transport.
