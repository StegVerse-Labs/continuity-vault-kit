# Do Not Store Here (in plain text)

This vault template is designed for portability and continuity.
It is not an encrypted safe by default.

Do NOT store the following in plain text inside this vault:

- passwords
- private keys / seed phrases
- banking numbers
- full social security numbers
- authentication recovery codes
- medical records you wouldn’t want exposed
- anything that could cause direct harm if leaked

If you need to store these, use:
- a password manager
- encrypted containers
- separate secure storage

When in doubt: don’t store it here.
