# 📱💻 Using KnowledgeVault Across Multiple Devices

Many people use more than one device — iPhone, iPad, laptop, or desktop — to capture notes, media, and ideas.

KnowledgeVault is designed so everything lives in **one unified vault**, while still remembering **which device something came from**.

This keeps your life archive simple, searchable, and future‑friendly.

---

## 🧭 The Key Idea: Device Context

Instead of creating separate vaults per device, we keep:

✔ One vault  
✔ One timeline  
✔ One set of folders  

But we add **optional device context** to entries.

Think of it like photos — they’re all in one library, but still tagged with which camera took them.

---

## 🧩 How to Tag an Entry with a Device

Add this line near the top of a note:

```
Device: iPhone 16 Pro
```

Examples:

```
Device: iPad Air (Travel)
Device: MacBook Pro
Device: Work PC
```

You can add this to notes like:

- Song Moments  
- Travel Logs  
- Emotional Snapshots  
- Event Logs  
- Research Notes  
- Writing Drafts  

This line is optional, but very helpful later.

---

## 📁 Media from Different Devices

Photos and videos already contain hidden device metadata, but a simple folder structure helps:

```
04_Media/
  Photos/
    iPhone/
    iPad/
    Camera/
  Videos/
    iPhone/
    iPad/
```

You don’t have to move everything at once — just follow this for new imports if you want extra clarity.

---

## 🔍 How to View Data from a Specific Device

Because “Device:” is written in plain text, you can:

- Search **Device: iPhone** to see only iPhone-captured memories
- Search **Device: MacBook** to find laptop-created notes
- Ignore device info and see everything normally

No technical setup required.

---

## 🧠 Device Index (Optional)

If you like extra structure, create:

`_Index/Device Index.md`

Example:

```
# Device Index

## iPhone 16 Pro
- [Song Moment – Artist – Title](../01_Notes/...)

## MacBook Pro
- [Writing Draft – Chapter 3](../01_Notes/...)
```

This helps both humans and AI navigate by device context.

---

## 🤖 Why This Matters for AI

Because device context is standardized, AI tools can later help answer questions like:

- “Show notes created while traveling”  
- “Find writing done on my laptop vs phone”  
- “What memories were captured on my old iPad?”

This adds another layer of life context without adding complexity.

---

## ✨ Simple Rule

**We do not separate data by device.**  
We **tag device context** so it can be filtered later.

This keeps KnowledgeVault:

✔ Unified  
✔ Easy to use  
✔ Flexible  
✔ Future‑intelligent
