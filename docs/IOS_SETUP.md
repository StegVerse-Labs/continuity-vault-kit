# iOS Setup (Recommended)

This kit is designed to work on iPhone/iPad without requiring a laptop.

## Recommended app stack (best experience)

### 1) Obsidian (navigation + links)
Use Obsidian Mobile to browse the vault like a real knowledge base.
- Relative links work well
- Folder browsing is fast
- Works offline if stored locally

**How:**
1. Download your private vault zip (or use your own folder in Files).
2. Unzip into: iCloud Drive or On My iPhone.
3. In Obsidian → **Open folder as vault** → choose your KnowledgeVault folder.
4. Start at `_Index/Master_Index.md`.

### 2) Working Copy (Git on iOS)
Use Working Copy for:
- cloning repos
- committing
- pushing
- branching

**Tip:** Keep the **starter kit repo public**, but keep your **real vault private** or local-only.

### 3) Pretext (editing, not navigation)
Pretext is excellent for quickly editing Markdown files.

⚠️ **Important:** Pretext often behaves like an editor, not a wiki browser.
- Some links may not “open” like they do on GitHub or Obsidian.
- If links don’t behave as expected, use **Obsidian** or the **GitHub web UI**.

### 4) Files app (storage + backup)
Use Files for:
- long-term storage
- iCloud Drive sync
- copying a “cold backup” to external storage

---

## Where links will work reliably

- ✅ **GitHub web UI** (inside the repo)
- ✅ **Obsidian**
- ✅ Many Markdown viewers
- ⚠️ **Pretext** (often edits instead of navigating)

---

## Suggested workflow (simple)

1. Keep this repo as the **public starter kit**
2. Create a **private vault repo** (or local vault folder)
3. Use the kit’s folder structure inside your private vault
4. Use Obsidian to browse, Pretext to edit, Working Copy to commit (if private repo)

---

## Privacy reminder

Do not store personal records in this public starter kit repo.

If you are using a Git repo for your real vault, make it **private**.
