# Emoji Style Guide

Use a small set of **universal iOS emojis** as consistent visual cues.

## Canonical set

- 🧠 Concept / philosophy
- 🧭 Navigation / where to go next
- 🧱 Structure / folder architecture
- 🧰 Tooling / scripts / automation
- 🛟 Recovery / backups
- 🔒 Safety / privacy boundary
- ✅ Do this
- ⚠️ Warning
- ❌ Do not do this
- 🧪 Testing / validation
- 🧾 Record / logs
- 🧬 StegDB-managed / standardized
- 💡 Ideas / suggestions

## Arrows

Avoid editor-specific arrow glyphs. Use either:

- ➜ (emoji)
- `-->` (ASCII)
